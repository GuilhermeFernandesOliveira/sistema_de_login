Projeto desenvolvido em linguagem C com foco em lógica de programação e testes de software.

## Funcionalidades
- Cadastro de usuário
- Login com validação de credenciais
- Verificação de usuário e senha
- Menu interativo no terminal
- Utilização de structs, funções e manipulação de strings para gerenciamento de dados.

## Objetivo
Praticar conceitos de programação, manipulação de strings, estruturas de dados básicas e validação de funcionalidades através de testes de software.
