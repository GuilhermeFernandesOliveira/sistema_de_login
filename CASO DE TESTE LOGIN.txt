CASO DE TESTE LOGIN

Teste 1 - Opção inválida no menu

Passos:
1. Abrir o sistema
2. Inserir uma opção inexistente no menu

Resultado esperado:
Mensagem: "Opção inválida!"


Teste 2 - Cadastro de usuário válido

Passos:
1. Abrir o sistema
2. Escolher a opção Cadastrar
3. Inserir um nome de usuário válido
4. Inserir uma senha válida

Resultado esperado:
Mensagem: "Conta cadastrada com sucesso!"


Teste 3 - Login válido

Passos:
1. Abrir o sistema
2. Escolher a opção cadastrar
3. Cadastrar um usuário
4. Escolher a opção Login
5. Inserir o usuário correto
6. Inserir a senha correta

Resultado esperado:
Mensagem: "Login realizado com sucesso!"


Teste 4 - Senha/Usuário incorreto

Passos:
1. Abrir o sistema
2. Escolher a opção cadastrar
3. Cadastrar um usuário
4. Escolher a opção Login
5. Inserir o usuário correto
6. Inserir uma senha incorreta

Resultado esperado:
Mensagem: "Usuário ou senha incorretos!"


Teste 5 - Usuário inexistente

Passos:
1. Abrir o sistema
2. Escolher a opção Login
3. Inserir um usuário não cadastrado
4. Inserir qualquer senha

Resultado esperado:
Mensagem: "Usuário ou senha incorretos!"


Teste 6 - Usuário já cadastrado

Passos:
1. Abrir o sistema
2. Escolher a opção cadastrar
3. Cadastrar um usuário
4. Depois escolher novamente a opção cadastrar
5. Inserir o mesmo nome do usuário já cadastrado antes

Resultado esperado:
Mensagem: "Usuário já cadastrado!"
