CASO DE TESTE LOGIN

Teste 1 - Opção inválida no menu

Passos:

1. Abrir o sistema
2. Inserir uma opção inexistente no menu

Resultado esperado:
Mensagem: "Opcao invalida!"

Teste 2 - Cadastro de usuário válido

Passos:

1. Abrir o sistema
2. Escolher a opção Cadastrar
3. Inserir um nome de usuário válido
4. Inserir uma senha válida

Resultado esperado:
Mensagem: "Conta cadastrada com sucesso!"

Teste 3 - Login válido

Passos:

1. Abrir o sistema
2. Escolher a opção Cadastrar
3. Cadastrar um usuário
4. Escolher a opção Login
5. Inserir o usuário correto
6. Inserir a senha correta

Resultado esperado:
Mensagem: "Login realizado com sucesso!"

Teste 4 - Senha/Usuário incorreto

Passos:

1. Abrir o sistema
2. Escolher a opção Cadastrar
3. Cadastrar um usuário
4. Escolher a opção Login
5. Inserir o usuário correto
6. Inserir uma senha incorreta

Resultado esperado:
Mensagem: "Usuario ou senha incorreta! Tentativa 1 de 3."

Teste 5 - Usuário inexistente

Passos:

1. Abrir o sistema
2. Escolher a opção Login
3. Inserir um usuário não cadastrado
4. Inserir qualquer senha
5. Repetir mais duas tentativas inválidas

Resultado esperado:
Após três tentativas inválidas, o sistema deve exibir:

Mensagem: "Usuario ou senha incorreta!"

Mensagem: "Nao tem um cadastro ainda? Escolha a opcao 1 no menu para se cadastrar!"

Teste 6 - Usuário já cadastrado

Passos:

1. Abrir o sistema
2. Escolher a opção Cadastrar
3. Cadastrar um usuário
4. Escolher novamente a opção Cadastrar
5. Inserir o mesmo nome de usuário já cadastrado

Resultado esperado:
Mensagem: "Usuario ja cadastrado!"

Teste 7 - Enviar uma Letra/Palavra/Frase ao invés de um Número

Passos:

1. Abrir o sistema
2. Inserir a letra G

Resultado esperado:
Mensagem: "Entrada invalida, insira um numero:"

(Este teste se aplica em todas as ocasiões em que o sistema solicita um número)

Teste 8 - Excluir conta

Passos:

1. Abrir o sistema
2. Cadastrar um usuário
3. Escolher a opção Excluir conta
4. Inserir o usuário correspondente ao que foi cadastrado
5. Inserir a senha correspondente ao usuário cadastrado

Resultado esperado:
Mensagem: "Conta excluida com sucesso!"

Teste 9 - Usuário inexistente ou Senha incorreta na exclusão da conta

Passos:

1. Abrir o sistema
2. Cadastrar um usuário
3. Escolher a opção Excluir conta
4. Inserir um usuário não cadastrado (ou incorreto)
5. Inserir uma senha qualquer

Resultado esperado:
Mensagem: "Usuario ou senha incorreta!"

Teste 10 - Limite máximo de contas

Passos:

1. Abrir o sistema
2. Cadastrar 100 usuários
3. Tentar cadastrar um 101º usuário

Resultado esperado:
Mensagem: "Limite de contas atingido!"

Teste 11 - Login após exclusão da conta

Passos:

1. Abrir o sistema
2. Cadastrar um usuário
3. Excluir a conta
4. Tentar realizar login utilizando as credenciais da conta excluída
5. Repetir mais duas tentativas inválidas

Resultado esperado:
Após três tentativas inválidas, o sistema deve exibir:

Mensagem: "Usuario ou senha incorreta!"

Mensagem: "Nao tem um cadastro ainda? Escolha a opcao 1 no menu para se cadastrar!"

Teste 12 - Login com usuário excluído e recadastrado

Passos:

1. Abrir o sistema
2. Cadastrar um usuário
3. Excluir o usuário
4. Cadastrar novamente o mesmo usuário
5. Escolher a opção Login
6. Inserir o usuário recadastrado
7. Inserir a senha correspondente

Resultado esperado:
Mensagem: "Login realizado com sucesso!"

Teste 13 - Alterar senha sem conta cadastrada ou com credenciais inválidas

Passos:

1. Abrir o sistema
2. Escolher a opção Alterar senha
3. Inserir um usuário não cadastrado (ou incorreto)
4. Inserir uma senha qualquer

Resultado esperado:
Mensagem: "Usuario ou senha incorreta!"

Teste 14 - Alterar senha

Passos:

1. Abrir o sistema
2. Cadastrar um usuário
3. Escolher a opção Alterar senha
4. Inserir o usuário correspondente ao que foi cadastrado
5. Inserir a senha correspondente ao usuário cadastrado
6. Inserir uma nova senha diferente da senha atual

Resultado esperado:
Mensagem: "Senha alterada com sucesso!"

Teste 15 - Alterar senha utilizando a mesma senha antiga

Passos:

1. Abrir o sistema
2. Cadastrar um usuário
3. Escolher a opção Alterar senha
4. Inserir o usuário correspondente ao que foi cadastrado
5. Inserir a senha correspondente ao usuário cadastrado
6. Inserir a mesma senha novamente

Resultado esperado:
Mensagem: "Senhas iguais! Tente novamente:"

O sistema deve solicitar uma nova senha até que seja informada uma senha diferente da atual.

Teste 17 - Login com a senha antiga após alteração

Passos:

4. Escolher a opção Login
5. Inserir o usuário correto

Teste 18 - Limite de tentativas no login

Passos:

1. Abrir o sistema
2. Escolher a opção Login
3. Inserir um usuário inexistente (ou incorreto)
4. Inserir uma senha qualquer
5. Repetir o procedimento mais duas vezes

Resultado esperado:
Após três tentativas inválidas, o sistema deve exibir:

Mensagem: "Usuario ou senha incorreta!"

Mensagem: "Nao tem um cadastro ainda? Escolha a opcao 1 no menu para se cadastrar!"

Teste 19 - Login correto após uma tentativa incorreta

Passos:

1. Abrir o sistema
2. Cadastrar um usuário
3. Escolher a opção Login
4. Inserir uma senha incorreta
5. Inserir o usuário e a senha corretos na segunda tentativa

Resultado esperado:
Mensagem: "Login realizado com sucesso!"
